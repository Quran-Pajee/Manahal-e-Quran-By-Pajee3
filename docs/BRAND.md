# Manahil-e-Quran Academy by PAJEE: brand guide

## Name

- Brand name: **Manahil-e-Quran Academy**
- Signature: **by PAJEE**
- Urdu: مناہلِ قرآن اکیڈمی
- Arabic: أكاديمية مناهل القرآن
- Manahil (مناهل) means springs: the places people come to for water.

Always write the name with this spelling and these hyphens.

## Logo

The mark is an open Quran inside a mihrab arch. The gold eight-point star above the book is the sign printed in the Quran to divide it into its parts.

| File (in `public/brand/`) | Use it for |
|---|---|
| `manahil-logo-primary.svg` / `.png` | The full logo: letterheads, certificates, social profile banners, print |
| `manahil-logo-horizontal.svg` / `.png` | Website header, email signature, anywhere wide and short |
| `manahil-icon.svg` / `.png` | The mark alone: social profile picture, stamps, watermarks |
| `...-reversed` versions | The same three on dark emerald backgrounds |
| `manahil-app-icon-512.png`, `-192.png`, `.svg` | App and home-screen icon (square, emerald background) |
| `manahil-favicon.svg`, `favicon.ico`, `favicon-16/32/48.png` | Browser tab icon |
| `apple-touch-icon.png` | iPhone home screen |

All text in the SVG files is converted to shapes, so they look the same on every computer with no font installed. PNG files have transparent backgrounds (the app icons are solid on purpose).

**Rules**
- Keep clear space around the logo equal to the height of the star.
- Smallest sizes: horizontal logo 120 px wide; the mark alone 24 px. Below 24 px use the favicon files, which are drawn simpler.
- Use the standard logo on ivory or white, and the reversed logo on emerald. Do not place either on photos or on gold.
- Do not stretch it, recolour it, add shadows or outline it.

## Colours

| Name | Hex | Use |
|---|---|---|
| Deep Emerald | `#123D32` | Primary: headings, main buttons, dark sections |
| Antique Gold | `#C7A45D` | Accents only: hairlines, the star, the one main button on a dark section |
| Warm Ivory | `#FAF7EF` | Page background |
| White | `#FFFFFF` | Cards and forms |
| Charcoal | `#26332E` | Body text |

Helpers used on the website, derived from the above: `#7A5C1E` (gold dark enough for small text on ivory), `#E3DCCB` (hairlines), `#F2EDDF` (quiet panels), `#55635C` (secondary text).

Gold text on ivory or white is too pale to read at small sizes. For gold-coloured text use `#7A5C1E`.

## Type

| Role | Typeface |
|---|---|
| English headings | Cormorant Garamond, semibold |
| Body text, forms, numbers | Inter |
| Arabic and Urdu | Noto Naskh Arabic |

All three are free and open-source (Google Fonts). On the website they are hosted with the site, so nothing is fetched from another company.

## The arch

The mihrab arch from the logo is the brand's own shape. On the website it frames the free-trial form and the lesson example, and nothing else. Keep it rare so it stays special.
